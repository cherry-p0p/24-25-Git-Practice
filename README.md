# GDGoC-Gachon 24-25 Git Practice

### ✨ 설명
효과적인 Git 협업 방법을 학습하도록 GDGoC-Gachon 24-25 Git Practice 세션 자료 제작 및 진행

### ✨ 주요 학습 내용
1. **Issue 및 PR 관리**  
   - 체계적인 작업 공유 및 기록을 통해 팀원 간 명확한 커뮤니케이션과 협업 역량 강화

2. **Branch 및 Commit 관리**  
   - 작업 분리를 위한 브랜치 전략과 체계적인 커밋 히스토리 관리를 통한 프로젝트 구조 최적화

3. **PR 템플릿 활용**  
   - 코드 리뷰 프로세스의 일관성과 효율성을 확보하여 팀원 간 피드백 및 개선 과정을 표준화

4. **Commit Message 규칙 적용**  
   - 통일된 커밋 메시지 컨벤션을 활용해 프로젝트 변경 사항의 추적성을 높이고, 코드 변경 의도와 맥락을 명확히 전달
